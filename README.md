# Olimpiadas de matemáticas

Preparación para las olimpiadas de matemáticas, de la nacional a la IMO: cómo reconocer cada familia de problemas de combinatoria, teoría de números, álgebra y geometría, las técnicas que la resuelven, problemas resueltos, simulacros con reloj y el trabajo de la delegación.

**Ver en línea:** https://aaramirez.github.io/olimpiadas-de-matematicas/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
